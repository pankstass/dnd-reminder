# Discord Event Reminder Bot

Discord-бот для автоматических напоминаний о регулярных событиях (Scheduled Events).

Бот отслеживает запланированные события на сервере и автоматически отправляет уведомления участникам.

---

## Возможности

### Автоматические сообщения

| Время | Условие | Что отправляет |
|-------|--------|----------------|
| **10:00** | Сегодня есть событие | Утреннее напоминание |
| **За 1 час** до начала | До старта события остался 1 час | Напоминание «через 1 час» |
| **23:05** | Сегодня было событие | Анонс следующего события |

Все автоматические сообщения:
- Пингуют указанную роль
- Содержат динамические Discord timestamp
- Содержат прямую ссылку на событие

### Slash-команды

| Команда | Описание | Видимость |
|--------|----------|---------|
| `/next` | Показать следующее событие | Всем |
| `/today` | Информация о сегодняшнем событии | Всем |
| `/events` | Список ближайших 5 событий | Всем |
| `/ping` | Проверить работу бота + задержку | Всем |
| `/time` | Текущее время сервера | Только вам |
| `/help` | Список всех команд | Только вам |

## Техническая информация

### Используемые технологии
- **Node.js** + **discord.js v14**
- **node-cron** — для расписания
- **dotenv** — для переменных окружения
- Хостинг: Railway / Oracle Cloud / любой VPS

### Переменные окружения (`.env`)

| Переменная | Описание |
|-----------|----------|
| `TOKEN` | Токен Discord-бота |
| `CLIENT_ID` | Application ID бота |
| `GUILD_ID` | ID Discord-сервера |
| `CHANNEL_ID` | ID канала для автоматических сообщений |
| `ROLE_ID` | ID роли, которую нужно пинговать |

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/event-reminder-bot.git
cd event-reminder-bot
npm install
```

### 2. Настройка `.env`

Создайте файл `.env` и заполните:

```env
TOKEN=ваш_токен_бота
CLIENT_ID=ваш_client_id
GUILD_ID=id_сервера
CHANNEL_ID=id_канала
ROLE_ID=id_роли
```

### 3. Регистрация команд

```bash
node deploy-commands.js
```

### 4. Запуск

```bash
node index.js
```

Или через PM2:

```bash
pm2 start index.js --name event-bot
pm2 save
pm2 startup
```

## Как работает логика

1. Бот получает список Scheduled Events сервера.
2. Фильтрует события по ключевому слову (настраивается в коде).
3. Определяет:
   - Сегодняшнее событие
   - Следующее будущее событие
4. По расписанию отправляет соответствующие сообщения.

Timestamp формируются через Discord-формат `<t:UNIX:STYLE>`, поэтому каждый пользователь видит время в своём часовом поясе.

## Настройки (в коде)

В начале файла `index.js` можно изменить:

```js
const CONFIG = {
  eventNameIncludes: 'Название события', // фильтр по названию
  timezone: 'Europe/Moscow',             // часовой пояс
  dayReminderHour: 10,                   // час утреннего напоминания
  dayReminderMinute: 0,
};
```

## Примеры автоматических сообщений

### Утреннее напоминание (10:00)
```
@Role воскресенье, 18 октября 2026 г. в 18:00 **Название события** — не забудьте.

⏳ Начало через 8 часов
🔗 [Событие](ссылка)
```

### Напоминание за 1 час
```
@Role Через **1 час** начинается **Название события**!

⏳ через 1 час
🔗 [Событие](ссылка)
```

### Анонс следующего события (23:05)
```
@Role Следующее **Название события**

📅 воскресенье, 1 ноября 2026 г. в 18:00
⏳ через 14 дней

🔗 [Открыть событие](ссылка)

Не забудьте отметить **Интересно**!
```
